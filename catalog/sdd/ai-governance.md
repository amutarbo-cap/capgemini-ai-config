# SDD: AI Governance Baseline

## Scope

Base mínima de gobierno para soluciones con IA en entornos empresariales.

## Controls

- Registro de prompts y outputs para auditoría.
- Clasificación de datos y políticas de redacción.
- Trazabilidad de versión de modelo y configuración.
- Revisión humana para decisiones de alto impacto.
