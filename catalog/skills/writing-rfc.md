# Skill: Writing RFC

## Goal

Estandarizar cómo se redactan RFCs técnicos para decisiones relevantes en proyectos de IA.

## Template

1. Contexto
2. Problema
3. Objetivos / No objetivos
4. Opciones consideradas
5. Decisión
6. Impacto (arquitectura, seguridad, costes)
7. Plan de migración
8. Métricas de éxito
