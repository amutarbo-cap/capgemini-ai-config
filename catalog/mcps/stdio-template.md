# MCP Template (stdio)

## Intent

Plantilla base para integrar herramientas a través de Model Context Protocol usando stdio.

## Required

- Definición de capacidades
- Contrato de entrada/salida
- Estrategia de errores
- Timeouts y límites

## Minimal checklist

- Health check
- Logging estructurado
- Validación de input
- Manejo de errores con códigos consistentes
